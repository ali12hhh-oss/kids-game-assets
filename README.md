# تعلّم مع ريبو — Android Native

تطبيق تعليمي للأطفال مبني باستخدام Kotlin وJetpack Compose.

## التقنية الحالية

- Android Native (Kotlin)
- Jetpack Compose وMaterial 3
- Android Gradle Plugin 8.7.3
- Kotlin 2.0.21
- Java 17
- `minSdk`: 23
- `targetSdk` / `compileSdk`: 35

## البناء والتحقق

سير عمل GitHub Actions في `.github/workflows/android-ci.yml` يتحقق من إعداد Gradle، ثم ينفذ `:app:assembleDebug` و`:app:testDebugUnitTest`. عند نجاح الخطوات يرفع ملف APK كأثر باسم `kids-learning-debug-apk`.

المشروع حاليًا في مرحلة تأسيس. الواجهة الحالية نموذج أولي، وليست الوظائف التعليمية النهائية. لا تُعتبر عملية البناء ناجحة إلا بعد اكتمال تشغيل سير العمل بنجاح.

## الأصول

مجلد `assets/` محفوظ كما هو. لا تُحذف الأصول أو تُنقل أثناء تجهيز البنية الأساسية.
